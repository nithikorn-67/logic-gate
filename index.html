REDSTONE BASICS

วงจร Redstone
ง่ายๆ ที่ทุกคนสร้างได้ง่าย ๆ ด้วย html

เรียนรู้การสร้างวงจร Redstone เบื้องต้น ตั้งแต่สวิตช์ไปจนถึงหลอดไฟ พร้อมต่อยอดสู่ระบบอัตโนมัติและตรรกะขั้นสูง — เนื้อหาแบ่งเป็น 8 บท อ่านทีละหน้าตามลำดับ หรือข้ามไปหัวข้อที่สนใจได้เลย

// เป้าหมายของบทเรียน

"เปิด/ปิดไฟจากระยะไกล"

โจทย์เริ่มต้นของเราคือการทำให้หลอดไฟติดและดับได้ โดยที่สัญญาณควบคุมมาจากสวิตช์ที่อยู่ห่างออกไป — เหมือนสวิตช์ไฟจริงในบ้านนั่นเอง เนื้อหาทั้งหมดถูกแบ่งเป็นบทย่อยด้านล่าง ไล่ตั้งแต่พื้นฐานไปจนถึงระบบอัตโนมัติขั้นสูง

🎯 โจทย์

ควบคุมไฟจากระยะไกล

ผู้เล่นกดสวิตช์ที่จุดหนึ่ง แล้วให้ผลลัพธ์เกิดขึ้นในอีกจุดหนึ่ง

⚡ สัญญาณ

ส่งผ่าน Redstone

Redstone Dust ทำหน้าที่เป็นสายไฟที่นำสัญญาณเดินทาง

💡 ผลลัพธ์

หลอดติด/ดับตามสวิตช์

Redstone Lamp แสดงผลลัพธ์ปลายทางของวงจร

// สารบัญ

เลือกบทที่อยากอ่าน

แนะนำให้อ่านตามลำดับ 01 → 08 ถ้าเป็นครั้งแรก แต่ถ้าเข้าใจพื้นฐานอยู่แล้ว สามารถข้ามไปหัวข้อที่สนใจได้ทันที

01

ชิ้นส่วนหลัก

Lever, Redstone Dust, Redstone Lamp — สามส่วนพื้นฐานที่ประกอบเป็นทุกวงจร

 02

ระยะสัญญาณ

ทำไมสัญญาณไปได้แค่ 15 บล็อก และวิธีขยายระยะด้วย Repeater (มีดีโม่โต้ตอบได้)

 03

ขั้นตอนสร้างวงจร

ลำดับการวางอุปกรณ์และทดสอบทีละขั้น ตั้งแต่วงจรง่ายสุดจนถึงแตกไฟหลายดวง

 04

ตัวกระตุ้นสัญญาณ

Button, Pressure Plate, Tripwire Hook — ทางเลือกอื่นนอกจาก Lever

 05

Logic Gate

AND / OR / NOT — นำหลักตรรกะดิจิทัลมาสร้างวงจรที่มีเงื่อนไข พร้อมอธิบายวิธีสร้างจริงในเกม

 06

พัลส์และจังหวะเวลา

สร้างสัญญาณสั้นๆ และวงจรนาฬิกา (Clock Circuit) เพื่อควบคุมจังหวะ

 07

ต่อยอดสู่ระบบอัตโนมัติ

นำวงจรพื้นฐานไปประกอบเป็นโปรเจกต์จริง เช่น ประตูอัตโนมัติ ฟาร์ม

 08

สรุปทั้งหมด

ทบทวนทุกหัวข้อในหน้าเดียว พร้อมเคล็ดลับก่อนเริ่มลงมือสร้างจริง
