ทำไมเราถึงต้องการ Logic Gate

วงจรที่ผ่านมาในบทก่อนๆ ทั้งหมดตอบคำถามแค่ "มีสัญญาณหรือไม่มี" — กดสวิตช์แล้วหลอดติด ไม่กดก็ดับ แต่ในความเป็นจริง ระบบที่ซับซ้อนมักต้องการ "ตัดสินใจ" จากเงื่อนไขหลายอย่างพร้อมกัน เช่น ประตูห้องนิรภัยจะเปิดก็ต่อเมื่อทั้งสวิตช์ A และสวิตช์ B เปิดพร้อมกันเท่านั้น หรือระบบแจ้งเตือนจะทำงานเมื่อมีอย่างน้อยหนึ่งเซนเซอร์ตรวจพบความผิดปกติ

นี่คือจุดที่แนวคิด Logic Gate จากวิชาวงจรดิจิทัล (Digital Logic) เข้ามาเกี่ยวข้อง — มันคือ "กฎการตัดสินใจ" ที่รับสัญญาณเข้า (input) หนึ่งหรือสองทาง แล้วให้ผลลัพธ์ (output) ตามกฎเฉพาะของมัน ในโลกคอมพิวเตอร์จริง ชิปประมวลผลทุกตัวก็ประกอบขึ้นจากเกตพื้นฐานเหล่านี้นับล้านตัวต่อกัน

หัวใจของทุกเกต: Redstone Torch

ในเกม Minecraft เราสร้างเกตเหล่านี้ขึ้นจากอุปกรณ์ Redstone พื้นฐานที่มีอยู่แล้ว โดยเฉพาะ Redstone Torch ที่มีคุณสมบัติพิเศษเฉพาะตัวคือ "ดับเมื่อบล็อกที่มันติดอยู่ได้รับสัญญาณ" พูดง่ายๆ คือ ถ้าไม่มีสัญญาณเข้ามา torch จะติดสว่างและปล่อยสัญญาณออกไป (ค่าเริ่มต้นคือ ON) แต่ทันทีที่มีสัญญาณมาเข้าที่บล็อกด้านหลังมัน มันจะดับทันที (กลายเป็น OFF)

พฤติกรรม "กลับด้าน" นี้ทำให้ torch หนึ่งอันทำหน้าที่เป็นเกต NOT ได้ในตัวเอง และเมื่อนำ torch หลายตัวมาต่อกันในรูปแบบต่างๆ ก็จะได้เกต AND, OR ตามมา — เกตทั้งหมดด้านล่างนี้จึงเป็นเพียงการจัดเรียง torch และสายไฟในรูปแบบที่ต่างกันเท่านั้น

คือ Redstone Torch เพียงตัวเดียว วางติดกับบล็อกที่รับสัญญาณอินพุต — ปกติ torch จะติดสว่างและปล่อยสัญญาณออก (out = 1) แต่ทันทีที่บล็อกด้านหลังมันได้รับสัญญาณ (in = 1) มันจะ ดับทันที ทำให้ output กลายเป็น 0 ใช้สร้างประตูที่ "ปิดเมื่อกดสวิตช์" แทนที่จะเปิด

ต่อเกตหลายตัวเข้าด้วยกัน (Combinational Logic)

พลังที่แท้จริงของ Logic Gate อยู่ที่การนำหลายเกตมาต่อกันเป็นห่วงโซ่ เช่น นำ output ของ OR Gate สองตัวไปเป็น input ของ AND Gate อีกตัวหนึ่ง เพื่อสร้างเงื่อนไขแบบ (A หรือ B) และ (C หรือ D) — ยิ่งต่อเกตมากขึ้น เงื่อนไขก็ยิ่งซับซ้อนและละเอียดขึ้นเรื่อยๆ เหมือนกับการเขียนเงื่อนไข if ซ้อนกันในภาษาโปรแกรมมิ่ง

ตัวอย่างที่พบบ่อยในโลกจริงของ Minecraft คือ ระบบล็อกประตูสองชั้น: ใช้ AND Gate ตรวจว่าเลเวอร์ทั้งสองต้องเปิดพร้อมกัน จากนั้นนำ output ไปเข้า NOT Gate อีกชั้น เพื่อทำให้ประตู "ปิดค้าง" เมื่อเงื่อนไขไม่ครบ และเปิดได้ก็ต่อเมื่อครบเงื่อนไขเท่านั้น — เป็นการผสมสามเกตพื้นฐานเข้าด้วยกันเพื่อแก้โจทย์ที่ซับซ้อนขึ้น

เกตขั้นสูงที่ควรรู้จักไว้ (XOR / NOR)

เมื่อคุ้นเคยกับสามเกตพื้นฐานแล้ว ยังมีเกตประกอบที่มีประโยชน์มากในการสร้างระบบซับซ้อน:

NOR Gate (NOT + OR): ติดก็ต่อเมื่อ "ทั้งสองอินพุตปิด" เท่านั้น สร้างได้จากการเอา NOT Gate ไปต่อท้าย OR Gate ใช้ทำระบบที่ต้องการให้ทำงานเฉพาะตอน "ไม่มีอะไรกระตุ้นเลย" เช่น ไฟฉุกเฉินที่ติดเฉพาะตอนไม่มีสัญญาณไฟหลัก

XOR Gate (Exclusive OR): ติดเมื่ออินพุต "ต่างกัน" เท่านั้น (A=1,B=0 หรือ A=0,B=1) แต่ถ้าทั้งคู่เหมือนกันจะดับ ในเกมมักสร้างจากการผสม AND, OR, NOT หลายตัวเข้าด้วยกัน ใช้ทำสวิตช์ไฟบันไดแบบ 2 จุดที่สลับสถานะกันได้ (กดจุดไหนก็ได้เพื่อสลับ ไม่ใช่แค่เปิด)
